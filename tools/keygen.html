Ключи сервера EEES

Три случайных ключа по 32 байта (base64, 44 знака), созданные в вашем браузере. Эта страница ничего никуда не отправляет — можно открыть её без интернета.

SIGNING_KEY
INDEX_KEY
DATA_KEY

Куда вставлять: Cloudflare → Workers & Pages → afflux-server → Settings → Variables and Secrets → Add, тип Secret, имя как в таблице, значение — ключ целиком. INDEX_KEY и DATA_KEY распечатайте и уберите в два разных места: без них зашифрованные данные участников не прочитать никому. Для ротации ключей создайте новые здесь же и действуйте по server/README.md, раздел Key rotation.
